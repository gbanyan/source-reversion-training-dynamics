# Fact-cluster sensitivity report

This supplementary report reweights the existing canonical rows so that each
`(category, subject, Y)` fact tuple contributes one observation. It is a
sensitivity analysis, not a replacement for the primary item-cluster
estimands. No model inference or source-data modification was performed.

## Analysis definition

- **Input:** `phase_a_det_shard0.json`, `phase_a_det_shard1.json`,
  `phase_a_7b_shard0.json`, `phase_a_7b_shard1.json`, and the ten canonical
  source-patch files used for Table 4.
- **Cluster key:** `(category, subject, Y)`; item rows sharing this fact are
  averaged before the grand mean.
- **Trajectory:** item-by-checkpoint reversion is first averaged within the
  121 item clusters, then within the 28 fact clusters. The data-selected
  extrema search is rerun for each fact-bootstrap draw.
- **Patch:** matched early/late rows are averaged within fact clusters before
  the absolute-q and paired-delta summaries. Confidence intervals are 10,000
  fact-cluster bootstrap draws.
- **Seeds:** trajectory `20260831`; patch groups `20260901` through `20260910`.

expected estimand difference, not a correction to the primary result.

## Scope and limitation

The local checkout does not contain semantic raw rows with stable subject/fact
keys. `cross_family_semantic_pool.json` exposes family/template summaries but
not the underlying semantic item identifiers, so a semantic fact-cluster
sensitivity analysis is not reported here. It should be added when the raw
semantic matrix is deposited in the public archive.
